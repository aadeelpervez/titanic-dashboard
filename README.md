# 🚢 Titanic Data Analytics Dashboard

An interactive data analytics project built with Python and Streamlit to explore Titanic passenger data and understand survival patterns.

## 📌 Project Overview

This dashboard helps users explore passenger information and analyse survival trends through interactive data visualisations.

## 🎯 Project Objectives

- Explore passenger demographics.
- Analyse survival patterns.
- Compare survival across passenger groups.
- Present findings through interactive charts.

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Plotly

## 📂 Project Files

- `app.py` — Dashboard application.
- `titanic.csv` — Passenger dataset.
- `requirements.txt` — Python dependencies.

## ▶️ Run Locally

1. Clone or download this repository.
2. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the dashboard:

   ```bash
   streamlit run app.py
   ```
